# Surface: Reticly website (site/)

Mode: Persuade. Audience: friends the maintainer sends the link to (PC gamers, dark room, link from Discord). Action: download Reticly.exe from the latest GitHub release and run it past the unsigned warning. Proof: live recoil demo from the app's real spray data, real screenshots, the live community gallery, honest install and safety notes. Constraints: never mention any competitor; no invented users, reviews or endorsements; Astro static on Vercel at reticly.vercel.app.

## Direction contract

THESIS: The site is the crosshair's engineering drawing, a numbered set of dark drawing sheets where every part is measured, called out and signed. It refuses the gamer landing page (headline, screenshot, feature cards, neon glow).

OWN-WORLD: Dark plot ground #0E1012 with a faint CAD grid. Off-white 1px ink linework. Layers as color: amber #F5A524 for the reticle and actions, cyan #45C4D6 for dimensions, red #E5534B for spray paths and centerlines. B612 and B612 Mono lettering. Components: title block, revision table, parts list, numbered balloons with leader lines, dimension lines. No glow or gradients; depth only from overlapping line layers.

STORY: Friends see their crosshair drawn huge, learn it tracks recoil, try the spray, and see the real app and the gallery. They read honest install notes and download.

FIRST VIEWPORT: Sheet 01. The reticle fills the left two-thirds of the sheet at 12:1 (12:1 gives the 1 px outline a readable width), with cyan dimension lines and amber balloons 1–5 leading to short notes. Bottom right, a crowded title block whose largest cell is an amber DOWNLOAD (version, size and SHA-256 from GitHub). The top border holds sheet tabs 01–06, keyed 1–6. On desktop, the cursor is a full-screen CAD crosshair with a live coordinate readout.

FORM: Reticle spec drawing, position 3 of 7 on my grounded list, seed key 0227469f. Signature interaction: holding the mouse on sheet 02 fires the real spray pattern, plotting numbered hits and printing their coordinates. Motion: dimension lines draw in once; everything else is still; no motion under reduced-motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
