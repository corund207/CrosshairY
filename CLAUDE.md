# Reticly — guide for Claude

Native Windows crosshair overlay (a Crosshair X–style app) in C# / WinForms on .NET Framework 4.8. One self-contained exe, no installer, no NuGet packages. Imports Crosshair X, VALORANT and CS2 crosshair codes and has recoil-tracking crosshairs.

## Build & run

```powershell
.\build.ps1                               # -> bin\Reticly.exe (fetches the Roslyn compiler into .tools\ on first run)
.\build.ps1 -Run                          # build and launch
.\build.ps1 -Out build\Reticly-dev.exe # compile check while the app is running (bin\ exe is locked) — delete it afterwards
```

- No Visual Studio / .NET SDK / Python on this machine. Scripting = PowerShell, node, or small C# harnesses compiled with `.tools\roslyn\tasks\net472\csc.exe`.
- Before building to `bin\`, check `Get-Process Reticly`; if it is running, build elsewhere or ask the user to exit from the tray.
- Smart App Control is on: a freshly built unsigned exe can be blocked. Treat a launch failure as possibly that, not a code bug.
- Fonts (`src/Assets/Fonts/*.ttf`) are embedded as `Reticly.Fonts.*`; `build/app.ico` is generated by `tools/IconGen.cs`.

## Verifying UI without clicking

```powershell
$env:RETICLY_DATA = "<scratch folder>"   # use a copy of %APPDATA%\Reticly, never the user's live data
build\Reticly-dev.exe --snap crosshairs:1,designer:animate,keybinds:end <outDir> [height]
```

- Snap keys: `crosshairs:0|1|2` (Discover/Browse/Saved), `designer`, `designer:animate`, `keybinds`, `settings`, `randomizer`, `help`, `profiles`, `tour:N` (tour step), `patterns:Game~Weapon` (pattern editor; `_` = space), `update` (update dialog). Append `:end` to scroll to the bottom.
- Keep spaces out of snap arguments: `Start-Process -ArgumentList` splits on them.
- Snap mode uses its own mutex, so it runs alongside the user's instance.
- For render/animation logic, compile a harness against `src\Core`, `src\Render`, `src\Input`, `src\Overlay`, `src\Import` (+ `/r:System.Numerics.dll`). Drive it with `Animator.Load` / `Input("left", true)` / `Evaluate`, or `CrosshairRenderer.Render`.

## Data model essentials

- A crosshair is `List<object>` of layer dictionaries (Crosshair X format): `type` = `model` | `shape` | `text` | `image` | `draw`, with `position`, `firingOptions`, etc.
- Animation lives in `firingOptions`: trigger `mouseButton` (`left`/`right`/`autoplay`/`none`), `pressType`, `releaseBehavior`, `duration`, `startDelay`, overrides (`line`, `dot`, `position`, …) and `stages[]`. Each stage inherits the previous one (`J.Merge`).
- Recoil trackers are layers whose `firingOptions.recoilPattern` = `"Game|Name"`. `Recoil.Apply` regenerates the whole `firingOptions`; per-layer style is kept in `recoilScale`, `recoilRpm`, `recoilStable`, `recoilFx`, `recoilFxEnd`, `recoilInvert`, `recoilMirror`, `recoilLag`, `recoilOff`. New `recoil*` keys must be added to `Animator.MetaKeys` and `DesignerPage.TimingKeys`.
- Settings/profile fields are serialized by hand in `AppState.cs` (`ToJson` / `FromJson` / `Clone`). Add a field in all three.
- Custom recoil patterns live in `patterns.json` (`Recoil.SetCustom`/`SaveCustom`). A custom pattern whose key matches a built-in replaces it. Loadout slots carry `Scale` (stored on layers as `recoilFactor`) and an optional `CrosshairId`.
- `DesignerPage` has a property named `L` (the selected layer). Write translations there as `Core.L.T(...)`.

## Conventions

- Match the surrounding style: custom controls (`FlatButton`, `Dropdown`, `FieldBox`, `SettingRow`, `SettingsCard`, `KeyTable`, `CaptionLabel`, `WrapLabel`), colors from `Theme.*`, sizes through `Theme.S(px)`, icons via `Glyph.*`.
- Controls can be laid out before their constructor finishes — guard fields used in `OnLayout`.
- Don't `BeginInvoke` before a handle exists.
- UI copy is short, sentence case, and honest (e.g. recoil patterns are approximations; overlays can't see hits).
- Edit files with the Edit tool. Bash heredocs with backticks break, and `sed` mangles glyph characters.
